\# Workstation AI Status Board



複数人で共同利用するワークステーション上のAI利用状況を可視化するために開発したシステムです。



\## 背景



所属するゼミでは、複数人が1台のワークステーションを共同利用しており、特定のAIモデルに処理が集中すると、負荷が高まりワークステーションが停止することがありました。



そこで、各AIモデルの利用状況を可視化し、利用者が「実行中」「待機中」「空き」の状態を確認したうえで、混雑していないAIを選択できる仕組みを開発しました。



\## 主な機能



\* 複数AIモデルへのリクエスト管理

\* モデルごとの同時実行数の制御

\* 待機中・実行中リクエストの管理

\* AIモデルごとの稼働状況表示

\* 実行中・待機中・空き状態の可視化

\* 利用者数・待ち時間・実行時間の表示

\* 2秒間隔での画面自動更新

\* 各AIモデルのヘルスチェック



\## システム構成



\### `app.py`



FastAPIを利用したゲートウェイサーバーです。



主に以下を担当しています。



\* AIモデルへのリクエスト振り分け

\* 同時実行数の制御

\* 待ち行列の管理

\* 利用者・実行時間・待ち時間の管理

\* `/health` によるモデル稼働状況の提供

\* `/queue/status` による利用状況の提供



\### `board.py`



Streamlitを利用した利用状況表示画面です。



ゲートウェイから利用状況を取得し、各AIモデルの状態を表示します。



\### `style.css`



画面のデザインを管理しています。



開発初期は処理・表示・デザインが一つのファイルに混在していましたが、改良しやすくするために処理部分と表示・デザイン部分を整理し、CSSを外部ファイルとして分離しました。



\## UIの工夫



利用者が専門的な情報を読まなくても直感的に状況を把握できるよう、マクドナルドの注文状況画面を参考にしました。



各AIモデルについて、



\* 実行中

\* 待機中

\* 空き

\* 停止中



を一目で確認できるようにしています。

\## 実行方法



\### 1. Gatewayの起動



```bash

uvicorn app:app --host 0.0.0.0 --port 8080

```



\### 2. Status Boardの起動



別のターミナルで以下を実行します。



```bash

streamlit run board.py --server.address 0.0.0.0 --server.port 8501

```



\### 3. ブラウザからアクセス



```text

http://localhost:8501

```



\## 補足



本リポジトリにはLLMモデル本体は含まれていません。

`app.py` は、別途稼働している各AIモデルのAPIへリクエストを転送する構成になっています。
